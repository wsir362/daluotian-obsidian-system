# Classification Rules · 分类规则

> 新文件进入仓库时，按什么逻辑决定它的位置。

---

## 核心问题

**问自己：「它服务于我本周正在做的哪个项目？」**

| 答案 | 去向 |
|------|------|
| 有明确项目（示例项目/AI协作系统等） | `10-项目/XXX/` |
| 通用方法论（可跨项目复用） | `20-认知工具箱/` |
| 深度研究（不一定转化为行动） | `30-研究/` |
| 今天就要用（todo/daily/inbox） | `00-行动中枢/` |
| 心智模型/洞察/策略提炼 | `40-副脑/` | 跨项目的决策框架、核心判断、操作指南 |
| 已完成/过期/原始文件 | `90-归档/` |
| 暂时不确定 | `00-行动中枢/Inbox/`（3天内决定） |

## 20-认知工具箱 子分类映射

| 主题关键词 | 子分类 |
|-----------|--------|
| 品牌、营销、抖音、直播、电商、流量、投放 | `品牌与营销/` |
| 商业、创业、融资、公司管理、产品、市场 | `商业与创业/` |
| 思维、方法论、AI、框架、模型、认知、系统 | `思维与方法论/` |
| 职场、晋升、沟通、人际关系、考公、面试 | `职场与进阶/` |
| 内容、IP、视频、脚本、文案、拍摄、编导 | `内容生产/` |
| 不确定 / 原文待提炼 | `20-认知工具箱/{对应子分类}/学习输入/`（暂存） |

## 文件名规范

| 类型 | 格式 | 示例 |
|------|------|------|
| 笔记 | `主题描述.md` | `AI财务分析-DCET框架.md` |
| 日记 | `YYYY-MM-DD.md` | `2026-05-08.md` |
| 视频文字稿 | `来源_主题_日期.md` | `法山叔_性交易违法成本_原文.md` |
| 会议纪要 | `YYYY-MM-DD HH_会议主题.md` | `2026-04-15 20_会议纪要.md` |
| 学习原文 | `主题_原文.md` | `AI_Agent的12个底层原理_原文.md` |

## 禁止行为

- ❌ 用日期命名文件夹（日期只用于文件）
- ❌ 在根目录堆积未分类文件
- ❌ 把 `_原文` 文件放在工作目录（应进归档或学习输入）
