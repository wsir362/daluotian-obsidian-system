# Archive Rules · 归档规则

> 什么文件应该进入 90-归档/，怎么组织。

---

## 归档触发条件

| 场景 | 操作 |
|------|------|
| docx 已完成 md 转换 | docx 移入 `90-归档/原始文件/` |
| 学习原文已完成提炼 | 原文移入 `90-归档/原始文件/` |
| 项目执行素材不再活跃 | 移入 `90-归档/运营素材库/` |
| 文件产生冲突旧版 | 旧版移入 `90-归档/冲突旧版/` |
| 笔记过时/错误/被替代 | 标记为 `#归档` 或移入 `90-归档/` |

## 原始文件组织

```
90-归档/原始文件/
├── 00-个人研究/        ← 个人研究相关原始 docx
├── 10-项目/            ← 项目相关原始 docx
│   └── 道物天成/
├── 20-认知工具箱/      ← 认知工具相关原始 docx
├── 30-研究/            ← 研究相关原始 docx
└── skill/              ← skill 相关原始 docx
```

## 运营素材库组织

```
90-归档/运营素材库/
├── 武当山文案/         ← 已分类：前期讨论/推广文案/视频策划/IP与人物/产品策划/参考资料/对标文案
├── 早安祝福/           ← 节气/日期子文件夹
└── ...                 ← 其他运营素材
```

## 冲突旧版组织

- 不再创建 `.冲突归档/` 子目录
- 旧版文件直接以 `旧_xxx` 或 `xxx_旧版_时间戳` 命名
- 保留原始路径结构，但去掉空壳中间层

##  learned-rules 关联

- 规则 3（不再新建 .冲突归档/）
- 规则 4（运营素材库只放执行文件）
