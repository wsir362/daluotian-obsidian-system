## 文件处理规则

### .docx 文件
1. 复制到目标目录
2. 同步生成同名 `.md`（使用 python-docx）
3. 如果目标目录已有更新的 .docx，只补转 md，不覆盖 docx
4. 转换后，.docx 移入 `90-归档/原始文件/` 对应分类

### .md / .pdf / 图片 / 视频
- 直接复制到目标目录
- 跳过 `.DS_Store` 和 Word 临时文件 `~$*`

### 命名检查
- 如果文件名包含 `_原文`，标记为"学习资料"，默认进 `20-认知工具箱/学习输入/` 或 `Inbox/`
- 如果文件名包含日期（如 `26-4-8`），保留但不作为分类依据

## 同步后必做

```
同步完成 → 检查根目录重复 → 更新变更日志 → 汇报结果
```
