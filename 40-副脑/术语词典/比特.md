# 比特（bit）

**定义**：不确定性的单位。就像重量有千克、长度有米，不确定性有比特。

---

## 通俗解释

1948年前，人类没有不确定性的单位，只能说"不太确定""玄乎"——全是感觉，没有刻度。

香农发明了 bit。
> 比特就是熵的千克、熵的米、熵的度。

---

## 具体感受

| 事件 | 比特 |
|------|------|
| 抛一次硬币 | 1 bit |
| 扑克牌抽一张花色 | 2 bit |
| 抽一张具体牌（52张） | 不到6 bit |
| 双色球开奖（1700万种组合） | 约24 bit |
| 手机里随便一张照片 | 约2000万 bit |

---

## 本质

> 你每天在手机上看到的所有内容、脑子里冒出的念头、说出口的每一句话，底层都是一串"是/否"的答案堆起来的。

- 计算机只认0和1 → 本质是"是/否"
- AI能听懂你说话 → 每个字拆成成千上万个"是/否"判断
- 5G传视频 → 光速搬运"是/否"的答案

> 你以为你在用手机？不，你在和一个由 bit 编织的宇宙打交道。
