# Key Message

**定义**：品牌所有对外信息的核心源头。一份文档，规定了品牌是谁、卖什么、为什么值得买。

---

## 通俗解释

Key Message 是品牌对外说话的"宪法"。

- 达人种草时，可以有自己的创意和风格，但核心信息不能偏离
- 广告打折时，可以强调促销，但不能说出品牌没有的功能
- 官网讲技术时，可以深入细节，但价值主张必须一致

---

## 为什么重要

没有 Key Message 的品牌：
- 渠道A说"高端奢华"
- 渠道B说"性价比之王"
- 渠道C说"年轻潮流"
- 用户听了三个版本，不知道你是谁

有 Key Message 的品牌：
- 所有渠道围绕同一核心，各自发挥创意
- 用户在任何触点接触到的是"同一个品牌"

---

## 应用

- 写 Key Message 文档时，不超过3个核心信息点
- 给所有外包/合作方发 Key Message，作为创意边界
- 定期检查各渠道内容，看是否偏离 Key Message
