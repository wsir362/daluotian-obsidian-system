## 使用规则

### 1. 文件存放原则

| 文件类型 | 存放位置 | 说明 |
|---------|---------|------|
| Agent Prompt | `agents/` | 角色定义，长期维护 |
| 调度逻辑 | `skills/` | Coordinator 怎么调度 |
| 知识索引/任务缓存 | `memory/` 下对应子目录 | 只放索引和专用缓存，长期知识回到 `10-项目/` 或 `40-副脑/` |
| 任务产出 | `sessions/[日期]-[任务名]/` | 每个任务独立文件夹 |
| 最终成品 | `output/` 下对应子目录 | 可直接使用的文案/脚本，长期使用时回链到项目资产 |
| 模板 | `templates/` | 可复用的模板文件 |

### 2. Session 命名规范

```
格式：YYYY-MM-DD-任务简述
示例：
- 2026-05-12-新品X起号方案
- 2026-05-13-视频脚本-产品A
- 2026-05-14-竞品分析-赛道B
```

### 3. OpenCode 输出规则

**OpenCode 的内容生产过程必须写入 `造化司/` 下对应位置**：

- Agent 定义 → `agents/`
- 调度逻辑 → `skills/`
- 知识索引/任务缓存 → `memory/` 下对应子目录
- 任务产出 → `sessions/[任务名]/`
- 最终成品 → `output/` 下对应子目录
- 长期项目资产 → 回链或复制到 `10-项目/道物天成/内容资产/`

**禁止**：
- 不要把造化司当作平行知识库
- 不要把长期项目资产只留在 `造化司/`
- 不要在根目录散落临时文件

### 4. 与其他目录的关系

```
大罗天/
├── 造化司/          ← 新媒体蜂群系统（你在这里）
├── 00-行动中枢/     ← 日常行动、Today、工作流
├── 40-副脑/         ← 知识库（心智模型、洞察、策略）
├── subagent/        ← 大罗天系统的 Agent（planner/validator/archivist/executor）
├── skill/           ← 大罗天系统的 Skill（智囊团等）
└── ...
```

**关系说明**：
- `造化司/` 是新媒体蜂群的独立作战室
- `40-副脑/` 是通用知识资产库，`造化司/memory/` 只做新媒体任务索引和专用缓存
- `10-项目/道物天成/` 是项目事实和长期执行资产的主库
- `subagent/` 是大罗天系统的通用 Agent，`造化司/agents/` 是新媒体专用 Agent
- 可以互相引用，但不要混放

## 快速开始

1. **确认任务边界**：先按 `大罗天系统总控台.md` 判断任务属于新媒体执行
2. **调用主库资料**：优先读取 `10-项目/道物天成/` 和 `40-副脑/`
3. **跑任务**：在 `sessions/` 下创建任务文件夹，按调度逻辑调用 Skill
4. **输出成品**：把最终文案/脚本放到 `output/`
5. **回链项目**：长期使用的成品回链或复制到 `10-项目/道物天成/内容资产/`
