# 热点判断详细流程

> 5分钟内判断：这个热点值不值得追

---

## Step 1: 热点信息收集

向用户确认以下信息（缺失的追问）：

| 信息 | 必须/可选 | 说明 |
|------|----------|------|
| 热点内容 | 必须 | 一句话描述发生了什么 |
| 热点来源 | 必须 | 微博/抖音/小红书/新闻 |
| 热度数据 | 可选 | 热搜排名/讨论量 |
| 相关链接 | 可选 | 原始链接/截图 |

---

## Step 2: 五维打分

用以下维度打分（1-10分）：

### 1. 热度
```
- 10分：微博热搜前5/抖音热榜前3
- 7分：微博热搜前20/抖音热榜前10
- 4分：小范围讨论/圈层热点
- 1分：已经没人讨论
```

### 2. 相关度
```
- 10分：直接跟你的赛道相关（如美妆赛道追护肤品热点）
- 7分：间接相关（如职场赛道追AI热点）
- 4分：弱相关（如美食赛道追电影热点）
- 1分：完全不相关
```

### 3. 安全度
```
- 10分：正向热点/无争议
- 7分：中性热点/小争议
- 4分：有争议但可控
- 1分：负面热点/政治敏感/灾难
```

### 4. 时效性
```
- 10分：刚发生（2小时内）
- 7分：还在发酵（6小时内）
- 4分：已过高峰期（12小时内）
- 1分：已过气（24小时+）
```

### 5. 可聊性
```
- 10分：有强烈个人观点可输出
- 7分：有独特角度可切入
- 4分：纯事实，无观点空间
- 1分：无话可说
```

---

## Step 3: 判断结论

### 判断标准

| 总分 | 结论 |
|------|------|
| 40-50 | 强烈推荐追 |
| 30-39 | 可以追，找好角度 |
| 20-29 | 谨慎追，除非角度特别好 |
| <20 | 不追 |

### 特殊规则（一票否决）

- 安全度 < 4 → 不追（负面热点）
- 相关度 < 4 → 不追（硬蹭）
- 时效性 < 4 → 不追（过气了）

---
