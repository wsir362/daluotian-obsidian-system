# 找切入角度方法

> 把热点跟你的账号定位关联起来

---

## 核心原则

**不是蹭热点，是借热点讲你想讲的话。**

---

## Step 1: 确认账号定位

向用户确认（或从 memory 中读取）：

| 信息 | 说明 |
|------|------|
| 赛道 | 你做什么领域 |
| 人设 | 你的账号人设 |
| 核心观点 | 你一直在传递的观点 |
| 目标用户 | 你的粉丝是谁 |

---

## Step 2: 找关联点

用以下 4 个方法找关联：

### 方法 1: 观点借势
```
热点事件 → 你想表达的观点 → 借热点说出来

示例：
热点：某明星塌房
你的观点：做人要有边界感
切入：借明星塌房讲"边界感的重要性"
```

### 方法 2: 知识迁移
```
热点事件 → 你的专业知识 → 用专业角度解读热点

示例：
热点：某公司裁员
你的专业：职场规划
切入：从裁员事件讲"如何打造不可替代性"
```

### 方法 3: 情绪共鸣
```
热点事件 → 大众情绪 → 你来提供情绪价值

示例：
热点：某地暴雨
大众情绪：焦虑/恐惧
切入：借暴雨讲"如何在不确定性中保持安全感"
```

### 方法 4: 反向思考
```
热点事件 → 主流观点 → 你提出不同视角

示例：
热点：某网红翻车
主流观点：活该
切入：借翻车讲"普通人如何避免被流量反噬"
```

---

## Step 3: 产出 3 个角度

```markdown
## 切入角度

### 角度 A: [标题]
- 类型：观点借势/知识迁移/情绪共鸣/反向思考
- 核心观点：[一句话]
- 关联度：高/中/低
- 风险：低/中/高

### 角度 B: [标题]
- 类型：
- 核心观点：
- 关联度：
- 风险：

### 角度 C: [标题]
- 类型：
- 核心观点：
- 关联度：
- 风险：

## 推荐
推荐角度 [A/B/C]，理由：[为什么]
```

---

## Step 4: 用户确认

让用户选择一个角度，进入口播稿写作。
