# 找差异化角度方法

> 找到"跟别人有什么不同"

---

## 核心原则

**差异化不是标新立异，是提供独特价值。**

---

## Step 1: 确认竞争情况

从选题卡中读取：
- 常见角度有哪些
- 差异化空间在哪里

---

## Step 2: 找差异化角度

用以下 5 个方法找差异化：

### 方法 1: 角度差异化
```
别人从A角度看 → 你从B角度看

示例：
选题：如何高效学习
常见角度：学习方法（怎么做）
你的角度：学习障碍（为什么学不进去）
```

### 方法 2: 深度差异化
```
别人讲表面 → 你讲本质

示例：
选题：职场沟通
常见角度：沟通技巧（怎么做）
你的角度：沟通心理学（为什么这样做有效）
```

### 方法 3: 案例差异化
```
别人用老案例 → 你用新案例

示例：
选题：创业思维
常见角度：马云/乔布斯案例
你的角度：身边小人物案例
```

### 方法 4: 形式差异化
```
别人严肃讲 → 你轻松讲

示例：
选题：理财知识
常见角度：专业术语
你的角度：用大白话讲
```

### 方法 5: 人群差异化
```
别人讲给所有人 → 你讲给特定人群

示例：
选题：时间管理
常见角度：通用方法
你的角度：专门讲给宝妈的时间管理
```

---

## Step 3: 产出 3 个角度

```markdown
## 差异化角度

### 角度 A: [标题]
- 差异化类型：[角度/深度/案例/形式/人群]
- 核心观点：[一句话]
- 跟别人的区别：[具体说明]
- 用户价值：[能解决什么问题]

### 角度 B: [标题]
- 差异化类型：
- 核心观点：
- 跟别人的区别：
- 用户价值：

### 角度 C: [标题]
- 差异化类型：
- 核心观点：
- 跟别人的区别：
- 用户价值：

## 推荐
推荐角度 [A/B/C]，理由：[为什么]
```

---

## Step 4: 用户确认

让用户选择一个角度，进入口播稿写作。
