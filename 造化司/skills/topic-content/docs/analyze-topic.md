# 选题分析详细流程

> 深度分析选题价值和用户需求

---

## Step 1: 选题信息收集

向用户确认以下信息（缺失的追问）：

| 信息 | 必须/可选 | 说明 |
|------|----------|------|
| 选题内容 | 必须 | 你想聊什么 |
| 选题来源 | 可选 | 自己想的/看到的/用户问的 |
| 目标平台 | 必须 | 抖音/小红书/视频号 |
| 参考案例 | 可选 | 别人怎么写的 |

---

## Step 2: 用户需求分析

### 核心问题

用户搜这个选题时，想解决什么问题？

### 需求类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 信息需求 | 想知道是什么 | "什么是私域" |
| 方法需求 | 想知道怎么做 | "怎么做私域" |
| 工具需求 | 想要推荐工具 | "私域用什么工具" |
| 案例需求 | 想看成功案例 | "私域成功案例" |
| 避坑需求 | 想知道怎么避坑 | "私域常见错误" |

### 需求分析模板

```markdown
## 用户需求分析

**选题**：[选题内容]

**核心需求**：用户想解决 [什么问题]

**需求类型**：[信息/方法/工具/案例/避坑]

**需求强度**：强/中/弱
- 强：用户主动搜索
- 中：用户被动看到
- 弱：用户不关心

**需求场景**：用户在什么情况下会搜这个？
- 场景1：
- 场景2：
- 场景3：
```

---

## Step 3: 竞争情况分析

### 分析维度

| 维度 | 问题 |
|------|------|
| 内容量 | 有多少人写过这个选题？ |
| 内容质量 | 写得好不好？有没有爆款？ |
| 内容角度 | 别人从什么角度写的？ |
| 内容形式 | 口播/图文/短视频？ |
| 差异化空间 | 你能提供什么别人没有的？ |

### 竞争分析模板

```markdown
## 竞争情况分析

**内容量**：[多/中/少]

**内容质量**：
- 头部作品：[链接/描述]
- 腰部作品：[链接/描述]
- 尾部作品：[链接/描述]

**常见角度**：
- 角度A：[描述]
- 角度B：[描述]
- 角度C：[描述]

**差异化空间**：
- 空间1：[别人没覆盖的角度]
- 空间2：[别人讲得不深的地方]
- 空间3：[别人没用的形式]
```

```markdown
# 选题卡

## 基本信息
- 选题：
- 来源：
- 目标平台：
- 创建时间：

## 用户需求分析
- 核心需求：
- 需求类型：
- 需求强度：
- 需求场景：

## 竞争情况分析
- 内容量：
- 内容质量：
- 常见角度：
- 差异化空间：

## 选题价值判断
- 用户价值：高/中/低
- 差异化空间：大/中/小
- 可执行性：强/中/弱
- 综合判断：□ 值得做 □ 谨慎做 □ 不做

## 状态
- [ ] 选题分析完成
- [ ] 差异化角度已确认
- [ ] 口播稿已完成
```
