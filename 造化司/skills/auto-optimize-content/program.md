# 最短路径指南

> 5分钟上手 auto-optimize-content 工作流

---

## 极简版（3步搞定）

```
Step 1: 告诉我你要做什么内容
        → 我产出选题卡

Step 2: 确认选题卡
        → 我产出 3 个版本的 prompt

Step 3: 确认 prompt 版本
        → 我迭代 + 合并 + 输出终稿
```

---

## 标准版（带验收）

### Phase 01: 选题立项
```
输入：你的需求（一句话就行）
输出：选题卡 + 用户画像 + 内容定位
验收：用 acceptance-checklist.md 检查
```

### Phase 02: 三角度 Prompt
```
输入：确认后的选题卡
输出：3 个 prompt（情绪版/数据版/悬念版）
验收：用 consistency-check.md 检查一致性
```

### Phase 03: 内层迭代
```
输入：3 个 prompt
输出：每个 prompt 迭代 2-5 轮，产出多个版本
规则：最多 5 轮，超过人工介入
```

### Phase 04: 对比合并
```
输入：所有迭代版本
输出：comparison-table.md + 终稿
验收：终稿验收清单
```

---

## 你要准备什么

| 准备项 | 必须/可选 | 说明 |
|-------|----------|------|
| 产品信息 | 必须 | 卖点、价格、目标用户 |
| 平台选择 | 必须 | 抖音/小红书/视频号 |
| 内容形式 | 必须 | 口播/图文/短视频 |
| 参考案例 | 可选 | 竞品爆款链接 |
| 品牌调性 | 可选 | 人设、风格关键词 |

---

## 输出到哪里

所有产出物都写入：
```
造化司/sessions/[日期]-[任务名]/
```

最终成品复制到：
```
造化司/output/文案/
```
