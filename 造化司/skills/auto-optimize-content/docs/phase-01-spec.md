# Phase 01: 选题立项

> 目标：把模糊需求变成清晰的选题卡

---

## 输入

用户的一句话需求，例如：
- "我要推新品 X，出个内容方案"
- "这个产品怎么打小红书"
- "帮我写个口播脚本"

---

## 执行步骤

### Step 1: 需求澄清

向用户确认以下信息（缺失的必须追问）：

| 信息 | 必须/可选 | 示例 |
|------|----------|------|
| 产品/服务 | 必须 | 护肤品、课程、App |
| 核心卖点 | 必须 | 7天见效、0基础可学 |
| 目标平台 | 必须 | 抖音、小红书、视频号 |
| 内容形式 | 必须 | 口播、图文、短视频 |
| 目标用户 | 必须 | 25-35岁职场女性 |
| 价格区间 | 可选 | 99-199元 |
| 竞品参考 | 可选 | 某博主的爆款链接 |
| 品牌调性 | 可选 | 专业、亲和、高端 |

### Step 2: 竞品分析（可选）

如果用户提供了竞品参考或目标平台，执行：

1. 分析竞品爆款内容（标题、结构、钩子）
2. 提炼可复用元素
3. 找到差异化空间

### Step 3: 产出选题卡

```markdown
# 选题卡

## 基本信息
- 产品/服务：
- 目标平台：
- 内容形式：
- 创建时间：

## 核心卖点
- 主卖点：
- 次卖点：
- 信任背书：

## 目标用户
- 画像：
- 痛点：
- 场景：
- 决策障碍：

## 内容定位
- 一句话定位：
- 情绪钩子：
- 差异化角度：

## 参考案例
- [竞品1]：
- [竞品2]：

## 状态
- [ ] 用户已确认
```
