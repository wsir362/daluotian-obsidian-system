# Phase 03: 内层迭代

> 目标：对 3 个 prompt 分别迭代，产出多个版本

---

## 输入

- 3 个确认后的 prompt（`sessions/[任务名]/prompt-A.md`、`prompt-B.md`、`prompt-C.md`）

---

## 迭代规则

### 基本规则

| 规则 | 说明 |
|------|------|
| 每个 prompt 迭代 2-5 轮 | 最少 2 轮，最多 5 轮 |
| 每轮必须有改进点 | 不能原封不动重复 |
| 超过 5 轮必须人工介入 | 判断是否继续或换方向 |

### 质量阈值

每轮迭代后，用以下维度打分（1-10分）：

| 维度 | 阈值 | 说明 |
|------|------|------|
| 标题吸引力 | ≥ 7 | 用户看到标题会不会点 |
| 卖点清晰度 | ≥ 8 | 用户能不能秒懂卖点 |
| 情绪共鸣度 | ≥ 7 | 用户有没有被触动 |
| 转化路径完整度 | ≥ 8 | 用户知不知道怎么买 |

**规则**：所有维度都达标才能进入下一轮，否则重新迭代。

---

## 执行步骤

### Step 1: 第一轮迭代

用 prompt-A/B/C 分别生成第一版内容。

对每个版本打分：
```
版本：A-v1
- 标题吸引力：X/10
- 卖点清晰度：X/10
- 情绪共鸣度：X/10
- 转化路径完整度：X/10
- 总结：[改进点]
```

### Step 2: 第二轮迭代

基于第一轮的改进点，重新生成。

```
版本：A-v2
- 改进了什么：[具体改进]
- 打分：[各维度分数]
- 是否达标：是/否
```

### Step 3: 后续迭代

重复 Step 2，直到：
- 所有维度达标 → 进入 Phase 04
- 或达到 5 轮 → 暂停，人工介入

---

## 产出物

| 文件 | 位置 | 说明 |
|------|------|------|
| A-v1.md ~ A-v5.md | `sessions/[任务名]/versions/` | 情绪版各轮迭代 |
| B-v1.md ~ B-v5.md | `sessions/[任务名]/versions/` | 数据版各轮迭代 |
| C-v1.md ~ C-v5.md | `sessions/[任务名]/versions/` | 悬念版各轮迭代 |
| iteration-log.md | `sessions/[任务名]/iteration-log.md` | 迭代记录（每轮打分+改进点） |

---

```markdown
|------|-----------|-----------|-----------|---------|------|-------|
| v1   | 6/10      | 7/10      | 8/10      | 6/10    | ❌   | 标题不够吸引，转化路径不清晰 |
| v2   | 8/10      | 8/10      | 8/10      | 8/10    | ✅   | - |

## 数据版 (B)
...

## 悬念版 (C)
...
```
