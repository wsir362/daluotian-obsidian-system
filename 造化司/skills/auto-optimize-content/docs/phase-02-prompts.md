# Phase 02: 三角度 Prompt 设计

> 目标：基于选题卡，设计 3 个不同角度的 prompt

---

## 输入

- 确认后的选题卡（`sessions/[任务名]/选题卡.md`）

---

## 三个角度定义

### 角度 A: 情绪共鸣版

**核心逻辑**：先打动人心，再植入卖点

**Prompt 结构**：
```
你是内容创作专家。基于以下选题卡，创作一篇以情绪共鸣为主的内容：

选题卡：[粘贴选题卡]

要求：
1. 前3秒必须引发强烈情绪（共鸣/好奇/争议）
2. 用故事/场景带入，不要直接卖货
3. 卖点作为"解决方案"自然出现，不要硬植入
4. 结尾留情绪钩子（引发评论/转发）

输出格式：
- 标题（情绪版）
- 正文/脚本（分段标注情绪节点）
- 封面文案（6字以内情绪钩子）
- 评论区引导（3条预埋评论）
```

### 角度 B: 数据说服版

**核心逻辑**：用数据/事实建立信任

**Prompt 结构**：
```
你是内容创作专家。基于以下选题卡，创作一篇以数据说服为主的内容：

选题卡：[粘贴选题卡]

要求：
1. 前3秒抛出数据/事实（引发信任）
2. 用对比/前后/竞品数据证明卖点
3. 引用权威背书（报告/专家/销量）
4. 结尾用数据制造紧迫感

输出格式：
- 标题（数据版）
- 正文/脚本（分段标注数据来源）
- 封面文案（核心数据点）
- 评论区引导（3条预埋评论）
```

### 角度 C: 悬念钩子版

**核心逻辑**：用悬念留住用户，逐步揭晓

**Prompt 结构**：
```
你是内容创作专家。基于以下选题卡，创作一篇以悬念钩子为主的内容：

选题卡：[粘贴选题卡]

要求：
1. 前3秒制造悬念（"你知道吗..."、"99%的人不知道..."）
2. 分段揭晓，每段留小钩子
3. 卖点作为"答案"在中后段揭晓
4. 结尾反转或留新悬念

输出格式：
- 标题（悬念版）
- 正文/脚本（分段标注悬念节点）
- 封面文案（悬念钩子）
- 评论区引导（3条预埋评论）
```

## 执行步骤

### Step 1: 设计 3 个 Prompt

基于选题卡，按上述结构设计 3 个 prompt。

### Step 2: 一致性检查

用 `templates/consistency-check.md` 检查 3 个 prompt 的一致性：

| 检查项 | A情绪版 | B数据版 | C悬念版 | 是否一致 |
|-------|--------|--------|--------|---------|
| 核心卖点 | | | | |
| 目标用户 | | | | |
| 转化路径 | | | | |
| 品牌调性 | | | | |

**关键**：核心卖点不能矛盾，目标用户必须一致。

### Step 3: 产出物

| 文件 | 位置 | 说明 |
|------|------|------|
| prompt-A.md | `sessions/[任务名]/prompt-A.md` | 情绪版 prompt |
| prompt-B.md | `sessions/[任务名]/prompt-B.md` | 数据版 prompt |
| prompt-C.md | `sessions/[任务名]/prompt-C.md` | 悬念版 prompt |
| consistency-check.md | `sessions/[任务名]/consistency-check.md` | 一致性检查表 |
