# Phase 04: 对比合并 + 终稿输出

> 目标：从所有迭代版本中，逐模块对比合并，产出最终文案

---

## 输入

- 所有迭代版本（`sessions/[任务名]/versions/`）
- 迭代记录（`sessions/[任务名]/iteration-log.md`）

---

## 执行步骤

### Step 1: 筛选最优版本

从迭代记录中，筛选每个角度的最优版本：

| 角度 | 最优版本 | 选择理由 |
|------|---------|---------|
| 情绪版 | A-vX | [理由] |
| 数据版 | B-vX | [理由] |
| 悬念版 | C-vX | [理由] |

### Step 2: 逐模块对比

用 `templates/comparison-table.md` 进行逐模块对比：

```markdown
## 模块对比

### 标题
| 来源 | 内容 | 优点 | 缺点 | 是否采用 |
|------|------|------|------|---------|
| A-v2 | xxx | 情绪强 | 卖点弱 | ❌ |
| B-v3 | xxx | 数据可信 | 太硬 | ✅ 采用 |
| C-v1 | xxx | 悬念足 | 标题党 | ❌ |

### 前3秒钩子
...

### 卖点植入
...

### 促单话术
...

### 转化路径
...
```

### Step 3: 合并终稿

基于对比结果，逐模块合并：

```markdown
# 终稿

## 标题
[来自 B-v3，增加了情绪元素]

## 前3秒钩子
[来自 A-v2，保留情绪节点]

## 卖点植入
[来自 B-v2，用数据支撑]

## 促单话术
[来自 C-v3，用悬念收尾]

## 转化路径
[综合三个版本，取最完整]
```

### Step 4: 终稿验收

用 `templates/acceptance-checklist.md` 中的「终稿」部分验收。

---

## 产出物

| 文件 | 位置 | 说明 |
|------|------|------|
| comparison-table.md | `sessions/[任务名]/comparison-table.md` | 逐模块对比表 |
| 终稿.md | `sessions/[任务名]/终稿.md` | 最终文案 |
| 终稿-带标注.md | `sessions/[任务名]/终稿-带标注.md` | 标注了每个模块来源的版本 |

---

## 终稿验收清单

| 检查项 | 是否通过 |
|-------|---------|
| 标题吸引力 ≥ 8/10 | |
| 卖点清晰度 ≥ 9/10 | |
| 情绪共鸣度 ≥ 8/10 | |
| 转化路径完整度 ≥ 9/10 | |
| 合规风控 Agent 已审查 | |
| 用户已确认 | |

---

## 输出到最终位置

终稿确认后，复制到：
```
造化司/output/文案/[日期]-[任务名]-终稿.md
```

终稿输出后 → 任务完成，归档 Session
