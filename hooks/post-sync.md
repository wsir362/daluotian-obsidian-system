# Hook: Post-Sync · 同步后检查

> 触发条件：执行任何批量文件同步/移动后
> 作用：验证同步结果，发现残留问题

---

## 自动检查清单

- [ ] **根目录是否有未分类文件？**
  - 扫描目标目录根目录（深度=1）
  - 如果有 .md/.docx 文件，标记为"未分类"

- [ ] **是否有重复文件？**
  - 扫描目标目录根目录
  - 对每个文件，检查子目录（深度≥2）中是否有同名文件
  - 如果发现重复，列出清单报告用户

- [ ] **docx 是否已转 md？**
  - 检查是否有 .docx 文件没有对应的 .md
  - 如果有，自动补转或报告

- [ ] **变更日志是否已更新？**
  - 确认 `00-行动中枢/Meta/日志/变更日志.md` 已追加本次同步记录

## 发现异常时的动作

1. **生成检查报告**：
   ```
   === 同步后检查报告 ===
   新增文件：X 个
   未分类文件：Y 个（需手动分类）
   重复文件：Z 个（建议删除根目录版本）
   缺失 md：W 个（docx 未转换）
   ```
2. **把异常写入 corrections.md**（作为"同步后残留问题"）
3. **等用户确认后处理异常**

## 关联 learned-rules

- 规则 6（重组后验证残留）
