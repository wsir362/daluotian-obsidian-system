# Hook: Today Archive · 今日区归档

> 触发条件：每天首次启动时（或用户说"归档 Today"时）
> 作用：把 `Today/` 下昨天及之前的文件归档到正确分类

---

## 归档流程

### Step 1：扫描 Today/
```bash
ls 00-行动中枢/Today/*.md
```

### Step 2：按日期筛选
- **今天的文件**（YYYY-MM-DD = 今天）：保留，不归档
- **昨天及之前的文件**：进入归档流程

### Step 3：内容判断去向

读取文件内容，按关键词判断：

| 关键词 | 去向 |
|--------|------|
| 品牌、营销、抖音、直播、投放 | `20-认知工具箱/品牌与营销/` |
| 商业、创业、公司、产品、市场 | `20-认知工具箱/商业与创业/` |
| AI、框架、模型、思维、方法论 | `20-认知工具箱/思维与方法论/` |
| 职场、晋升、沟通、人际 | `20-认知工具箱/职场与进阶/` |
| 内容、IP、视频、文案、拍摄 | `20-认知工具箱/内容生产/` |
| 示例项目、示例地点、示例地点 | `10-项目/示例项目/内容资产/` |
| 两性、婚姻、彩礼、AI伴侣 | `30-研究/专题研究/` |
| 养老、意定监护、遗产 | `30-研究/《专题研究手册》/` |
| 香火、道教、宗教、民俗 | `30-研究/示例选题流转/` |
| 待办、todo、日记、今日 | `00-行动中枢/Daily/` |

### Step 4：执行归档
1. 移动文件到目标目录
2. 去掉日期前缀（或保留，看用户偏好）
3. 添加 `[[ ]]` 链接到相关笔记

### Step 5：清空 Today/
- 保留 `README.md`
- 删除已归档的文件

## 用户确认策略

**全自动模式**（推荐）：
- AI 自动判断、自动归档、自动清空
- 归档后在 Daily 记录归档清单

**半自动模式**：
- AI 列出归档计划
- 用户确认后再执行

## 与 Inbox 的联动

```
Inbox/ 原始素材 → 提炼 → Today/ 已提炼内容 → 次日归档 → 正确分类
```

## learned-rules 关联

- 规则 4（运营素材库只放执行文件）→ Today 不放运营素材
- 规则 7（分类前对齐用户预期）→ 首次使用时确认归档偏好
