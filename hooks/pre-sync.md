# Hook: Pre-Sync · 同步前检查

> 触发条件：执行任何批量文件同步/移动前
> 作用：拦截常见错误，避免同步后产生大量纠正

---

## 自动检查清单

- [ ] **路径映射是否正确？**
  - 检查 sync-rules.md 中的映射表
  - 确认目标目录存在（不存在则先创建）

- [ ] **是否会产生重复？**
  - 扫描目标目录根目录，检查是否有同名文件
  - 如果有，标记为"待处理重复"，不自动覆盖

- [ ] **文件类型是否合规？**
  - 检查是否有 `_原文` 文件被放入运营素材库
  - 检查是否有 `.DS_Store` 或 `~$*` 临时文件

- [ ] **数量是否合理？**
  - 单次同步超过 50 个文件时，先报告用户确认
  - 避免大批量误操作

## 发现异常时的动作

1. **暂停同步**
2. **向用户报告异常清单**：
   ```
   同步前检查发现以下异常：
   - [异常1] 描述 + 建议处理方式
   - [异常2] 描述 + 建议处理方式
   请确认是否继续？
   ```
3. **等用户确认后再执行**

## 关联 learned-rules

- 规则 1（同步后检查重复）→ 前置到同步前
- 规则 4（运营素材库只放执行文件）
