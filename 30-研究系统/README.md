# 30-研究系统

研究系统用于把一个模糊问题推进成可复用的认知资产。

它不直接保存原始资料堆积，而是强调四步：

1. 定义问题：明确研究对象、边界和判断标准。
2. 收集材料：保留来源、时间、可信度和反例。
3. 提炼结构：把材料抽象成模型、变量、因果链和适用条件。
4. 输出资产：沉淀为报告、模板、原则、MOC 或决策参考。

## 开源边界

研究流程和模板可以公开；真实研究对象、原始资料、访谈记录、项目细节、付费课程内容和带版权材料默认不公开。
