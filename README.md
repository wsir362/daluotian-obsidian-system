# 大罗天 Obsidian System

大罗天是一个面向个人知识管理、AI 决策协作和内容生产工作流的 Obsidian 系统模板。

这个仓库是开源模板版，只保留系统方法论、目录骨架、规则、模板、AI 协作协议和可复用工作流；不包含私人笔记、项目资料、客户资料、原始素材、日记、运行记录或归档文件。

## 适合谁

- 想用 Obsidian 搭建长期个人知识系统的人
- 想把 AI 助手接入个人工作流的人
- 需要沉淀决策、复盘、研究、内容生产流程的人
- 想把个人经验整理成可复用系统的人

## 核心结构

```text
.
├── 00-行动中枢/          # 每日行动、模板和入口
├── 20-认知工具箱/        # 内容、职场、AI、商业、品牌方法论
├── 30-研究系统/          # 研究项目、资料卡、报告和边界模板
├── 40-副脑/              # 副脑使用手册
├── 50-AI决策系统/        # AI 决策协作协议、模板和路由
├── hooks/                # 工作流钩子
├── rules/                # 分类、同步、归档规则
├── subagent/             # 多代理分工模板
├── 造化司/               # 内容生产与 AI 工作流模块
├── AGENTS.md             # AI 助手协作说明
└── agent.md              # 系统入口说明
```

## 使用方式

1. 下载或克隆本仓库。
2. 用 Obsidian 打开仓库目录。
3. 从 `00-行动中枢/Templates` 开始建立自己的每日笔记、学习记录和复盘。
4. 用 `20-认知工具箱` 承接可复用的方法论，而不是堆放原始资料。
5. 用 `30-研究系统` 把问题、材料、证据、反例和结论拆开管理。
6. 根据 `rules` 和 `hooks` 调整自己的分类、归档和同步流程。
7. 根据 `50-AI决策系统` 配置你的 AI 决策、分析和复盘流程。

## 开源版边界

本仓库刻意排除了以下内容：

- 个人日记、Inbox、Today、Daily
- 真实项目资料
- 客户、团队、商业案例
- 原始文件、PDF、Word、PPT、图片和视频素材
- 学习原文、付费资料、访谈记录和版权材料
- Obsidian 本地 workspace 状态和插件构建文件
- 密钥、token、数据库和本地配置

如果你基于本模板建立自己的系统，建议保持这个边界：模板可以公开，个人数据默认留在本地。

## GitHub Desktop 发布

3. 选择这个目录：`/Users/wsir/codex/大罗天-open`。

5. 第一次提交前，检查 `Changes` 列表里没有私人文件。
