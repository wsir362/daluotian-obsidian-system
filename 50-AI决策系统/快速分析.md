# 大罗天 · AI决策中枢 · 快速分析

## 功能简介

基于 Obsidian 本地知识库和 100+ 思维模型的决策分析系统。输入你的问题，AI 会：
1. 识别问题类型
2. 选择合适的分析模型
3. 判断是否需要调用 `40-副脑` 或 `造化司`
4. 引导你补充关键信息
5. 给出结构化的分析和行动建议
6. 将有价值结果沉淀为案例，必要时安排复盘

## 支持的问题类型

| 类型 | 示例 |
|---|---|
| 个人重大选择 | 该不该辞职？选 A 还是选 B？ |
| 商业/创业判断 | 该不该进入 XX 市场？这个生意能跑通吗？ |
| 产品/增长/私域 | 先做哪个功能？私域怎么设计？ |
| 新媒体运营 | 账号怎么起号？脚本怎么优化？ |
| 风险评估 | 这个项目值不值得做？什么时候止损？ |
| 知识库优化 | 这批笔记怎么归类？规则怎么沉淀？ |

## 使用方法

### 推荐方式：桌面一键进入 OpenCode

双击桌面的 `AI决策助手.command`。

它会自动：

```text
进入 /Users/wsir/codex/大罗天/50-AI决策系统
启动 OpenCode
提示 OpenCode 只读取 AI入口协议.md 完成轻启动
等待你在 OpenCode 里输入具体问题
```

进入 OpenCode 后，直接输入你的问题即可。

系统会先读取 `模型路由表.md` 判断问题类型，只有复杂问题才会读取完整 `AI决策助手.md`。

### 其他 AI 工具能读取本地文件时

在对应工具中发送：

```text
请读取 /Users/wsir/codex/大罗天/50-AI决策系统/AI入口协议.md，并按协议执行。

我的问题是：
[在这里粘贴你的问题]
```

### 其他 AI 工具不能读取本地文件时

1. 复制上方"问题输入区"的内容。
2. 打开 `AI入口协议.md`，全选复制。
3. 打开 AI 工具（Kimi / OpenCode / ChatGPT / Claude Code / KimiCode）。
4. 先粘贴入口协议和你的问题。
5. 如果 AI 提示需要模型库，再打开 `AI决策助手.md` 并复制。
6. 等待 AI 分析。

## 分析结果存档

分析完成后，把有价值的结论保存到 `案例/` 文件夹。

你可以直接对 AI 说：

```text
保存进系统
```

默认会保存到 `案例/`。如果你想保存成模板或复盘，需要明确说明。

```
案例/
├── 私域运营方案-滋补品.md    ← 已有案例
└── [日期]-[问题关键词].md    ← 新案例
```

如果需要后续验证，把复盘计划保存到 `复盘/` 文件夹。

```
复盘/
└── [日期]-[问题关键词]-30天复盘.md
```

## 系统变更记录

如果修改了目录、模板、协议、脚本或系统规则，必须更新：

```
CHANGELOG.md
```

普通案例分析不需要写入变更日志。
