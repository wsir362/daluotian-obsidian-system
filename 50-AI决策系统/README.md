# 大罗天 · AI决策中枢

## 这是什么

一个基于 Obsidian 本地知识库的个人 AI 分析决策系统。它不是某个 AI 工具的专属项目，而是一套跨工具可执行的工作流：Codex、Claude Code、OpenCode、KimiCode、ChatGPT 都可以按同一套协议使用。

核心目标：把复杂问题拆解成结构化分析、行动方案、案例沉淀和后续复盘。

## 核心原则

```text
文件是系统本体
协议是调用入口
AI 是执行器
案例是资产
复盘产生复利
变更日志记录演化
```

## 三层架构

| 层级 | 目录 | 作用 |
|---|---|---|
| 知识资产层 | `../40-副脑/` | 心智模型、洞察、策略、术语、MOC |
| 分析决策层 | `./` | 问题识别、模型选择、决策分析、案例复盘 |
| 新媒体执行层 | `../造化司/` | 起号、内容、私域、电商转化、合规、数据复盘 |

## 能帮你做什么

| 场景 | 示例问题 |
|---|---|
| 个人重大选择 | "该不该辞职创业？选A还是选B？" |
| 商业/创业判断 | "这个商业模式能跑通吗？" |
| 产品/增长/私域 | "增长停滞了怎么办？用户为什么流失？" |

| 风险评估 | "这个项目值不值得做？什么时候止损？" |
| 知识库优化 | "这批笔记应该怎么归类和沉淀？" |

## 怎么用

### 方式一：桌面一键进入 OpenCode

双击桌面的 `AI决策助手.command`。

它会自动进入：

```text
/Users/wsir/codex/大罗天/50-AI决策系统
```

然后启动 OpenCode，并提示它只读取 `AI入口协议.md` 完成轻启动。进入 OpenCode 后，直接输入你的问题；系统会在看到问题后再按需读取模型库和知识库。

### 方式二：跨 AI 工具通用入口

在任意 AI 工具中输入：

```text
请读取 /Users/wsir/codex/大罗天/50-AI决策系统/AI入口协议.md，并按协议执行。
```

如果当前 AI 工具不能直接读取本地文件，就手动复制：

1. `AI入口协议.md`
2. 你的具体问题
3. 必要时再复制 `AI决策助手.md` 或与问题相关的少量知识库笔记

### 方式三：手动复制使用

**第一步：打开 `AI入口协议.md`**

**第二步：输入你的具体问题，让 AI 判断是否需要模型库**

**第三步：如果 AI 工具不能读取本地文件，再手动复制 `AI决策助手.md` 或相关笔记**

**第四步：或使用 `模板/决策档案模板.md` 补充背景**

```
我是一个初创新媒体企业，目前在思考私域如何运行
```

**第五步：AI 会按格式输出分析**

```
📌 问题定义
🧰 选用模型
🔍 分析过程
⚠️ 逻辑自检
🎯 结论与行动
```

## 目录结构

| 文件/目录 | 作用 |
|---|---|---|
| `AI入口协议.md` | 所有 AI 工具的通用入口 |
| `模型路由表.md` | 轻量判断问题类型和候选模型，优先读取 |
| `AI决策助手.md` | 完整模型库、系统设定、输出格式，必要时读取且只读一次 |
| `快速分析.md` | 面向人的快速使用说明 |
| `CHANGELOG.md` | 系统级变更日志 |
| `模板/` | 决策档案、分析结果、复盘模板 |
| `Inbox/` | 待分析问题 |
| `分析中/` | 正在处理的问题 |
| `案例/` | 已完成分析案例 |
| `复盘/` | 30 天、60 天、90 天验证记录 |

## 模型库结构

| 域 | 解决什么问题 | 示例模型 |
|---|---|---|
| 域1：战略与竞争 | 在哪里竞争、如何取胜 | SWOT、波特五力、护城河 |
| 域2：商业模式与增长 | 如何赚钱、如何规模化 | AARRR、飞轮、LTV/CAC |
| 域3：产品与营销 | 做什么产品、如何定价 | JTBD、价格-价值地图 |
| 域4：组织与执行 | 如何落地、配置资源 | OKR、RACI、RICE |
| 域5：决策与风险 | 不确定性下如何选择 | 决策树、贝叶斯、情景规划 |
| 域6：系统与博弈 | 多主体互动、反馈优化 | 因果回路图、纳什均衡 |
| 域7：哲学与逻辑 | 确保思考本身正确 | 第一性原理、谬误识别 |

## 案例存档

分析完有价值的结论，保存到 `案例/` 文件夹。

建议命名：

```text
YYYY-MM-DD-问题关键词.md
```

如果结论需要后续验证，把复盘计划写入 `复盘/`。

用户说“保存进系统”时，默认保存到 `案例/`。只有明确说“保存成模板”“进入复盘”“沉淀成规则”时，才写入其他位置。

## 变更日志

修改目录、模板、协议、脚本、系统规则时，必须更新 `CHANGELOG.md`。普通案例分析不进入变更日志。
