**Kimi:**

**极简复盘模板**

遵循”金字塔原理”，每项写 **2-3 条**，问题/原因/行动**一一对应**：

| 模块 | 填写内容 |
| --- | --- |
| **目标** | 当初想达成什么效果？（量化） |
| **结果** | 实际完成情况？（对比目标） |
| **亮点** | 做得好的 2-3 个点（事实，非情绪） |
| **问题** | 存在的 2-3 个问题 |
| **原因** | 导致每个问题的根本原因（主观+客观） |
| **行动** | **继续保持** / **停止做** / **下次优化**（与问题一一对应） |

**示例对照（拉会员案例）：**

* **目标**：拉取会员 3 万个
* **结果**：达成 4 万个，超额完成
* **亮点**：①公域+私域结合 ②线上线下联动 ③老带新游戏机制
* **问题**：①羊毛党混入 ②老会员参与积极性不高
* **原因**：①活动缺乏门槛 ②活动力度吸引力不足
* **行动**：①**优化**：设置防薅门槛 ②**停止**：不再无差别拉新 ③**保持**：提前布置时间节点

**使用口诀**：目标结果要量化，亮点问题列三条，原因行动对得上，继续停止优化分清楚。
