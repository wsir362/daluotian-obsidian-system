**Kimi:**

基于这场面试模拟，我给你整理了一套**可直接落地的「商业战略分析岗」招聘面试框架**。核心思路是：**用压力测试逼出真实水位，用脚手架考察成长潜力，用作业题筛出自驱力。**

## 一、面试设计哲学：「凶」是手段，「辨伪」是目的

| 原则 | 操作方式 | 要筛掉的人 |
| --- | --- | --- |
| **不给背诵时间** | 跳过自我介绍，直接抠项目 | 简历包装过度、参与深度浅 |
| **拒绝形容词** | 打断”我负责整合数据”这类空话 | 只会做执行、不会提炼方法 |
| **即时压力测试** | 沉默10秒、接电话、连环追问 | 情绪不稳、抗压差、思维易涣散 |
| **现场给框架** | 候选人卡壳时，教一个模型看他能不能接住 | 学习能力差、僵化 |
| **结尾留作业** | 给3个灵魂问题，观察面试后反馈 | 自驱力差、对机会不渴望 |

## 二、面试流程设计（建议4轮，60-90分钟）

第1轮：简历深挖（20min） → 辨真伪
第2轮：方法论拷问（15min） → 看深度
第3轮：即时Case（25min） → 看实战
第4轮：潜力评估+作业布置（5min） → 看自驱

## 三、提问武器库（按考察维度分类）

### 维度1：项目真伪与颗粒度（辨真伪）

**不要问** “讲讲这个项目”
**要问：**

* “不用自我介绍了，挑一个你**最想让我记住**的项目，告诉我它解决了什么业务问题？”
* “你说整合数据，具体是哪些数据源？清洗规则是什么？”
* “拆分了哪些维度？客群、区域、渠道、产品，至少给我两个。”
* “最后输出的核心指标是什么？业务方因为你们这个分析做了什么决策？”

**红灯信号：** 只讲流程不讲指标；说不出数据维度；把”收集资料”说成”整合数据”。

### 维度2：模型化与可复用性（看深度）

**核心问题：** 你的经验是”一次性手艺”还是”可迁移资产”？

* “如果让你把这套方法教给应届生，能总结出几步SOP？”
* “你判断城市下沉优先级，主要靠经验还是模型？模型里有哪些量化指标？”
* “同样的分析框架，换一个行业还能用吗？哪些变量要换？”

**加分回答：** 主动提及”我当时建了一个评分卡/决策树/优先级矩阵”。

### 维度3：业务体感与指标敏感度（看基本功）

战略岗不能只会画PPT，必须懂**生意逻辑**：

* “新市场进入，至少要看哪三类指标？”
* “单点PNL和ROI，你会怎么估算？需要哪些假设？”
* “渗透率、转化率、渠道成本、RY，这几个指标在你项目里分别是多少？”

**技巧：** 故意说一个模糊词（如”市场容量”），看候选人是否会**先定义再计算**。

### 维度4：即时Case实战（看临场）

**推荐Case类型：** 市场进入（Market Entry）+ 市场规模估算（Market Sizing）

**示例Case（可直接用）：** > “一个国内小电驴品牌，预算有限，想半年内验证东南亚市场是否可行，你会怎么做？”

**观察点与追问清单：**

| 候选人表现 | 你的追问/施压 |
| --- | --- |
| 直接说”做东南亚” | “东南亚10个国家，你先验证哪几个？选国家的标准是什么？” |
| 提到泰国 | “快速估算泰国电动车市场容量。注意，先告诉我你算的是**量还是价值**。” |
| 给出数字 | “你的假设是什么？数据来源呢？如果泰国人均GDP数据偏差20%，结果差多少？” |
| 只讲市场大 | “市场大不代表你能拿下。竞争壁垒怎么建？数据怎么收集？” |
| 提到用户分层 | “如果把购买预算梯度拆细，你会用什么维度拆分人群？” |

**评估重点：** 不是答案对不对，而是**拆解框架是否完整、假设是否清晰、被挑战时能否修正**。

### 维度5：抗压与情绪恢复（隐性维度）

**操作手法：** - 故意打断一次：“这段不用继续了，直接说结果。” - 制造一次沉默：“给你10秒钟，想好了再说，不着急。”（观察呼吸、眼神、手部动作） - 演一场戏：假装接电话，然后对电话说”我在面试，别打扰”，观察候选人情绪是否崩掉。

**绿灯信号：** 被打断后能快速找到锚点继续；沉默时能结构化重组语言；干扰后能迅速回到问题。

## 四、候选人评估评分表（建议简化为5维度）

| 维度 | 权重 | 1-5分 | 本轮小T参考分 | 评估要点 |
| --- | --- | --- | --- | --- |
| **项目深度** | 25% |  | 3 | 是真操盘还是只参与？颗粒度到不到指标层？ |
| **结构化表达** | 20% |  | 2 | 是否结论先行？有没有”地图+位置”的表达习惯？ |
| **模型化能力** | 20% |  | 2 | 经验能否提炼为SOP/框架？是否依赖感觉？ |
| **业务体感** | 20% |  | 3 | 对PNL、ROI、渗透率等指标是否敏感？ |
| **抗压/学习力** | 15% |  | 4 | 被挑战时情绪稳不稳？给框架后能不能接住？ |

**决策线：** - **4.0+ 且无明显短板：** 强推，给offer - **3.0-3.9：** 可过，但需指定一个作业验证（见下文） - **3.0以下：** 挂，节省双方时间

## 五、结尾作业设计（筛自驱力，同时给下一轮递材料）

面试结束前，留3个问题让候选人**书面回复**（24-48小时内提交）：

1. **结果证明：** 你过去的工作内容到底解决了什么实际业务问题？请用”因为做了A，所以业务指标B提升了C”的格式写。
2. **方法论沉淀：** 选一个你最有信心的项目，输出一份不超过1页纸的**可复用分析框架/SOP**。
3. **专家级洞察：** 告诉我们一个**你所在领域别人不一定知道，但很有价值**的认知。

**作业评估标准：** - 交了 vs. 没交 → 直接筛掉没交的（自驱力不够） - 第1题有没有数字 → 区分”执行者”和”结果导向者” - 第2题能不能脱敏后复用 → 区分”项目经验”和”方法论资产” - 第3题有没有信息增量 → 区分”熟练工”和”顾问型选手”

## 六、面试官操作手册（如何扮演”凶但帮你”）

| 场景 | 错误做法 | 正确做法 |
| --- | --- | --- |
| 候选人背简历 | 耐心听完 | 直接打断：“不用自我介绍，直接说项目结果。” |
| 回答太空泛 | 点点头换话题 | 追问：“这个听起来太空了，具体用了什么分析方法？” |
| 候选人卡壳 | 马上换简单问题 | 沉默10秒，然后说：“不着急，想好了再说。” |
| 完全答不上来 | 直接挂掉 | 给一个脚手架：“教你个思路，从’值不值得、能不能、可不可以赚钱’三方面看…” 然后看他能不能基于这个框架重新答。 |
| 时间到了 | 客套结束 | 明确给作业+给反馈：“你过了/待定，但下一轮总经理很看重X，建议你重点准备Y。” |

## 七、一句话总结给你用

**招人不是找”答得完美”的人，而是找”被戳穿后还能重建逻辑、给脚手架后能往上爬”的人。**

小T在这轮面试里表现并不完美（表达平铺直叙、模型感弱、紧张），但面试官还是让他过了——因为**底子真实（项目确实做过）、抗压尚可（没崩）、学习力可验证（给了框架能听懂）**。

你招人时，也可以参考这个逻辑：**硬技能有缺陷可以补，思维框架和抗压底色很难改。**
