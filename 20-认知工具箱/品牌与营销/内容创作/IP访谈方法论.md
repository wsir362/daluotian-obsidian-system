### 一、先判断：这个人值不值得做深度口播？

不符合以下3点的，改做vlog/轻采访，别硬上。

| 特质 | 快速判断法 | 反面信号 |
| --- | --- | --- |
| **有真实故事** | 能讲出具体场景（时间、地点、动作、心理），不是概括叙事 | 只会说”我负债翻身”，讲不出那晚几点睡、手里拿了什么 |
| **足够坦荡** | 敢暴露脆弱/不完美，不装坚强 | 流量下滑时说”平台问题”，绝不承认自己焦虑失眠 |
| **有交互感** | 你点头/眼神回应时，他会讲得更兴奋 | 你反馈再多，他仍自顾自讲，像公司领导念稿 |

### 二、访谈前必做：4项调研（防气场被压）

没调研别上桌，否则你问的问题一定停留在表面。

1. **生平节点**：重大选择、遗憾、转折点——找只有他能讲的”缝隙”
2. **朋友圈视角**：他眼中的自己 vs 朋友眼中的他，找差异
3. **作品对比**：早期vs现在，反复强调什么、避而不谈什么
4. **行业现状**：他行业正在发生什么变化、真实困境是什么

**目的**：实现认知对齐，让他觉得”你懂我”，而不是”你在审我”。

### 三、破冰5步法（核心：让他忽略镜头）

破冰不是聊天气，是让他觉得”这个问题值得我开口”。

| 步骤 | 动作 | 禁忌 |
| --- | --- | --- |
| **1. 细节切入** | 用调研到的他无意识细节提问 | 别问宏大概念，别让他感觉你在”索取答案” |
| **2. 眼神锁定** | 盯着他的眼睛，身体前倾，点头回应 | **禁止看手机屏幕**，手机找人代录或调大焦距 |
| **3. 沉默重复** | 他卡顿时，停1-2秒，重复他最后一句话 | 别急着接话、别切换话题 |
| **4. 无痕拉回** | 聊偏时，语气平静地重复最初的问题 | 别说”我们回归主题”，他会出戏 |
| **5. 别写写画画** | 全程保持交流状态 | 记录会让他感觉被审视 |

**破冰成功标志**：他忘了镜头，沉浸在跟你的对话里。

### 四、提问公式：直接可用的问法

**1. 两类内容，两种问法**

| 类型 | 问什么 | 举例 |
| --- | --- | --- |
| **行业洞察** | 结果 + 差异化 + 具体案例 | “这个行业90%的人怎么做？你为什么反着做？当时第一个客户是谁？” |
| **人设故事** | 冲突 + 压力 + 深层动机 | “你当时和谁矛盾？为什么必须做这个决定？你自己都没意识到的那个点是什么？” |

**2. 画面感提问法（眼耳鼻舌身意）**

不问”你害怕吗？“（概念层） 要问”你当时手在干嘛？听到了什么？闻到什么？身体什么反应？“（场景层）

**3. 深挖公式**

**冲突 + 场景 + 转折点**

例：“当你知道要背300万债那晚，几点睡的？”

### 五、现场自我表达：共情，但不抢戏

| 该做 | 不该做 |
| --- | --- |
| “您刚才说的我特别有感触” | “我也有类似经历，我当年……”（抢主语） |
| 用肢体+简短回应（嗯、我明白）承接 | 情绪比他更激动，替他表达 |
| 让他感觉被听见、被触动 | 让他感觉你在表演”我理解你” |

### 六、编导双系统：你必须同时运行

| 系统 | 任务 | 自检 |
| --- | --- | --- |
| **倾听者系统** | 让他真的想讲、真的被触动 | 我是不是在真诚好奇？ |
| **编导系统** | 同步判断：哪段做钩子、哪段做金句、怎么排版 | 这段剪出来有人看吗？ |

**练习路径**： - 新手：先分开练——专门练聊天深挖 / 专门拿别人素材练剪辑预判 - 进阶：拍摄时允许自己短暂分神3-5秒，思考”这段能不能用” - 熟练：每天拍完当天复盘，连续1个月高强度练

### 七、拍摄铁律（4条，翻车高发区）

1. **收音第一**：即兴最好的段落，收音一炸全废。先检查设备再开机。
2. **珍惜第一条**：同个问题问第二遍，IP会”演”。**不要试录**。
3. **拍完等20秒再关机**：关机后他说的”刚才那个点其实可以这样说…“往往是真正放松的金句。
4. **他紧张，你也说紧张**：顺着紧张聊，等他肢体打开再切正题。

### 八、一句话心法

技术的终点是忘记技术。保持观察，保持好奇。能在线下让全场安静的内容，搬到线上也一定成立。

**好素材不在脚本里，在生活里。找到它，抓住它。**
